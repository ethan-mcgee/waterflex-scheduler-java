# Community 2.6.0 compatibility inventory

This inventory is a test backlog and an index of current coverage. An API name in newer documentation or inspected bytecode is not a passed behavior probe. Java 25 and the root/scheduler BOM pin remain 2.6.0. No dependency or production configuration changes are made in phase 1. Results of the existing tests are in verification.json; source and dependency hashes are in baseline.json.

Test classes below are under scheduler-service/src/test/java/dev/waterflex/scheduler/optimizer unless otherwise stated. Future tests belong to their owner step and must run against the recorded artifact version. Do not add the removed 1.x Timefold test artifact for ConstraintVerifier.
